# Agent Design

## Hermes Agent

Role:
Orchestrator

Responsibilities:
- Receive user requests
- Break tasks into smaller tasks
- Assign tasks to agents
- Track progress

## OpenClaw Agent

Role:
Coding Agent

Responsibilities:
- Write code
- Fix bugs
- Run tests

## QA Agent

Role:
Testing Agent

Responsibilities:
- Check outputs
- Find errors
- Report failures

## Reporting Agent

Role:
Reporting Agent

Responsibilities:
- Create summaries
- Generate reports
